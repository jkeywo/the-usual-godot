# Asset provenance

`original/*.svg`: original geometric pixel artwork authored for this port,
released under this repository's MIT license. No source imagery from the
restricted CozyHome or character packs was used or copied. Source SVGs use
integer-aligned rectangles and nearest-neighbour rendering.

`kenney_future_narrow.ttf`, `click-a.ogg`, `tap-a.ogg`: Kenney UI Pack, CC0,
retained from the baseline repository's documented curated subset.
https://kenney.nl/assets/ui-pack

The original repository's restricted sprites and raw asset packs are excluded
from this repository and its exports.
